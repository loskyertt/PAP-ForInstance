本文档说明当前仓库如何在 FOR-Instance 数据集上运行 PAP-FZS3D。

# 1. 当前适配状态

当前项目已经完成了 FOR-Instance 的主要适配，适配范围是：

- 将 FOR-Instance 原始 `.las` 转成项目可读的 `.npy`。
- 使用 `classification` 字段做语义分割标签。
- 将原始标签重映射为 5 个连续类别：
  - `0`: terrain
  - `1`: low_vegetation
  - `2`: stem
  - `3`: live_branches
  - `4`: woody_branches
- FOR-Instance 的块数据格式为 `[x, y, z, intensity, label]`。
- 数据加载器已支持 `label_col=4`，不会再按 S3DIS/ScanNet 的第 6 列读取标签。
- 数据加载器已支持 `I` 强度通道，因此推荐输入特征为 `xyzIXYZ`。
- `forinstance` 已接入 `main.py`、预训练、PAP 训练和 PAP 评估流程。

> [!warning] 注意
> 当前适配的是 FOR-Instance 的**语义少样本分割**任务，不是官方意义上的单木实例分割评估。FOR-Instance 原始数据包含 `treeID`，但当前项目没有使用它，也没有实现官方实例匹配指标。
> 当前结果只能解释为基于 `classification` 的语义少样本分割结果，不能直接作为 FOR-Instance 官方单木实例分割 benchmark 结果。

# 2. 环境准备

需要安装原 PAP-FZS3D/attMPTI 依赖，并额外确保以下包可用：

```bash
pip install laspy pandas tqdm h5py tensorboard
```

训练还需要 PyTorch 和 CUDA 环境。Windows 上建议在 Git Bash、WSL 或 Linux 服务器中运行这些 `.sh` 脚本。

# 3. 目录说明

## 3.1 data

原始 FOR-Instance 数据集存放在 `data/FORinstance_dataset` 目录下，该目录下包含：

```txt
data/FORinstance_dataset/
  CULS/
  NIBIO/
  RMIT/
  SCION/
  TUWIEN/
  data_split_metadata.csv
```

对 FOR-Instance 数据集的说明，请见文档 [01_数据集说明](01_数据集说明)。

## 3.2 datasets

类别文件为：

```bash
datasets/FORInstance/meta/forinstance_classnames.txt
```

内容必须保持以下顺序：

```txt
terrain
low_vegetation
stem
live_branches
woody_branches
```

预处理后的数据会统一生成到 `datasets` 目录下：

```bash
datasets/FORInstance/scenes_dev
datasets/FORInstance/blocks_dev_bs10.0_s5.0
```

- `datasets/FORInstance/scenes_dev` 是第一步预处理结果。里面通常是：

```text
datasets/FORInstance/scenes_dev/data/*.npy
```

每个 `.npy` 对应一个 plot，也就是一整块森林样地的点云。它是从 `.las` 清洗、标签映射后得到的中间数据。

- `datasets/FORInstance/blocks_dev_bs10.0_s5.0` 是第二步切块结果。里面主要是：

```text
datasets/FORInstance/blocks_dev_bs10.0_s5.0/data/*.npy
```

每个 `.npy` 是一个 10m x 10m 的 block。训练、预训练、few-shot episode 采样主要使用这里的数据。

> [!note]
> 它还会存放一些**后续训练/评估阶段由 dataloader 自动生成的缓存文件**，例如：
> ```text
> class2scans_label7_min5pct_100pts.pkl
> S_0_N_2_K_1_xyzIXYZ_label7_episodes_100_pts_2048/
> S_0_N_2_K_1_xyzIXYZ_label7_test_episodes_100_pts_2048/
> ```
> 这些是为了加速 few-shot episode 构造。`class2scans...pkl` 记录每个类别出现在哪些 block 里，`S_.../*.h5` 是已经采样好的 support/query episode。

```text
class2scans_label7_min5pct_100pts.pkl
```

**生成时机**：第一次实例化 `FORInstanceDataset` 时生成。

通常由这些脚本触发：

```bash
bash scripts/pretrain_forinstance.sh
bash scripts/train_PAP_forinstance.sh
bash scripts/eval_PAP_forinstance.sh
```

**作用**：扫描 `blocks_dev_bs10.0_s5.0/data/*.npy`，统计每个类别出现在哪些 block 中，缓存成 `class -> block names` 映射。之后再跑就不用重新扫描全部 `.npy` 了。

```text
S_0_N_2_K_1_xyzIXYZ_label7_episodes_100_pts_2048/
S_0_N_2_K_1_xyzIXYZ_label7_test_episodes_100_pts_2048/
```

**生成时机**：构造 few-shot validation/test episodes 时生成。

通常由这些脚本触发：

```bash
bash scripts/train_PAP_forinstance.sh
bash scripts/eval_PAP_forinstance.sh
```

**作用**：保存已经采样好的 support/query episode，每个 episode 是一个 `.h5` 文件。这样下次验证/测试时可以复用同一批 episode，保证评估更稳定，也省去重复采样开销。

名字含义：

```text
S_0        fold 0
N_2        2-way
K_1        1-shot
xyzIXYZ    输入特征
label7     当前数据标签列是第 7 列
episodes_100 / test_episodes_100
pts_2048   每个点云采样 2048 点
```

## 3.3 logs

- `log_forinstance` 是预训练日志目录。运行 `pretrain_forinstance.sh` 后会生成：

```text
log_forinstance/log_pretrain_forinstance_S0/checkpoint.tar
log_forinstance/log_pretrain_forinstance_S0/log_pretrain.txt
log_forinstance/log_pretrain_forinstance_S0/events.out.tfevents...
```

其中 `checkpoint.tar` 是预训练 encoder 权重，后续 PAP few-shot 训练会加载它。

- `log_forinstance_PAP` 是 PAP few-shot 训练和评估日志目录。运行 `train_PAP_forinstance.sh` 后会生成：

```text
log_forinstance_PAP/log_proto_forinstance_S0_N2_K1_Att1/checkpoint.tar
log_forinstance_PAP/log_proto_forinstance_S0_N2_K1_Att1/log_prototrain.txt
```

运行 `eval_PAP_forinstance.sh` 后会生成/追加：

```text
log_forinstance_PAP/log_proto_forinstance_S0_N2_K1_Att1/log_protoeval.txt
```

总体结构：

```text
logs/
├── log_forinstance/                                    ← 预训练阶段
│   └── log_pretrain_forinstance_S0/
│       ├── checkpoint.tar                              ← 预训练模型权重 (PyTorch 序列化, 46 个 tensor)
│       ├── events.out.tfevents...                      ← TensorBoard 日志
│       └── log_pretrain.txt                            ← 预训练日志文本
│
└── log_forinstance_PAP/                                ← PAP 小样本训练阶段
    └── log_proto_forinstance_S0_N2_K1_Att1/            ← S0 fold, 2-way 1-shot, 含 Attention
        ├── checkpoint.tar                              ← PAP 模型权重 (PyTorch 序列化, 76 个 tensor)
        ├── events.out.tfevents...                      ← TensorBoard 日志
        ├── log_prototrain.txt                          ← 训练过程日志
        └── log_protoeval.txt                           ← 最终评估日志
```

各文件含义

| 文件 | 本质 | 用途 |
|------|------|------|
| **`checkpoint.tar`** | PyTorch `torch.save()` 序列化的模型 `state_dict`（tar 打包格式） | 加载模型权重用于继续训练或推理评估 |
| **`events.out.tfevents.*`** | TensorBoard 事件文件（二进制） | `tensorboard --logdir=logs` 可视化 loss、IoU 等曲线 |
| **`log_pretrain.txt`** | 预训练文本日志 | 查看预训练过程、每 3 个 epoch 的 mIoU |
| **`log_prototrain.txt`** | PAP 小样本训练日志 | 查看 episodic 训练过程、每 2000 iters 的评估结果 |
| **`log_protoeval.txt`** | 最终评估日志 | 训练完成后单独运行评估的结果 |

# 4. 流程

## 4.1 数据预处理

运行：

```bash
bash scripts/preprocess_forinstance.sh
```

该脚本做两步：

1. `preprocess/collect_forinstance_data.py`
   从 `data/FORinstance_dataset` 读取官方 `dev` split 的 `NIBIO` 和 `SCION` 数据，然后再从原始 FOR-Instance `.las` 文件读取点云，过滤无效类别，重映射语义标签，生成 per-plot `.npy`。

2. `preprocess/forinstance2blocks.py`
   把 per-plot `.npy` 按滑窗切成块，将点云切成 10m block，滑窗步长为 5m，最少点数为 1024，默认参数如下：

```bash
--block_size 10.0
--stride 5.0
--min_npts 1024
```

输出目录就是 `datasets/FORInstance/blocks_dev_bs10.0_s5.0`。

默认脚本内容等价于：

```bash
python preprocess/collect_forinstance_data.py \
  --data_path ./data/FORinstance_dataset \
  --collections NIBIO SCION \
  --split dev

python preprocess/forinstance2blocks.py \
  --data_path ./datasets/FORInstance/scenes_dev \
  --block_size 10.0 \
  --stride 5.0 \
  --min_npts 1024 \
  --overwrite
```

如果想使用全部 dev 集合，可以把 `--collections` 改为：

```bash
--collections CULS NIBIO RMIT SCION TUWIEN
```

## 4.2 预训练特征提取器

运行：

```bash
bash scripts/pretrain_forinstance.sh
```

关键配置：

```bash
DATASET='forinstance'
DATA_PATH='./datasets/FORInstance/blocks_dev_bs10.0_s5.0'
PC_ATTRIBS='xyzIXYZ'
SAVE_PATH='./logs/log_forinstance/'
```

该脚本负责在 FOR-Instance 的 base/train classes 上预训练点云 encoder。训练完成后，checkpoint 应在：

```bash
logs/log_forinstance/log_pretrain_forinstance_S0/checkpoint.tar
```

## 4.3 训练 PAP few-shot 模型

运行：

```bash
bash scripts/train_PAP_forinstance.sh
```

默认设置是 fold 0、2-way 1-shot：

```bash
SPLIT=0
N_WAY=2
K_SHOT=1
PC_ATTRIBS='xyzIXYZ'
```

fold 0 的测试类是：

```txt
terrain, stem
```

训练类是：

```txt
low_vegetation, live_branches, woody_branches
```

负责训练 PAP few-shot 模型。它会加载上步的预训练 encoder checkpoint，然后进 2-way 1-shot episodic training。训练完成后，checkpoint 应在：

```bash
logs/log_forinstance_PAP/log_proto_forinstance_S0_N2_K1_Att1/checkpoint.tar
```

## 4.4 评估 PAP few-shot 模型

运行：

```bash
bash scripts/eval_PAP_forinstance.sh
```

评估脚本默认读取：

```bash
logs/log_forinstance/log_pretrain_forinstance_S0/checkpoint.tar
logs/log_forinstance_PAP/log_proto_forinstance_S0_N2_K1_Att1/checkpoint.tar
```

负责加载 PAP checkpoint，在 test classes 上做 few-shot 评估，输出 mloU 等结果。

> [!result]
> 所以，如果你已经有 `log_forinstance/.../checkpoint.tar`，可以跳过预训练；如果你已经有 `log_forinstance_PAP/.../checkpoint.tar`，甚至可以直接跑评估。弱从零开始，四个脚本应该都依次执行。

> [!warning]
> 如果你使用的是旧实验目录，例如仓库根目录下的：
> 
> ```bash
> log_forinstance/
> log_forinstance_PAP/
> ```
> 
> 则需要把脚本中的 checkpoint 路径改回对应目录，或者重新按当前脚本从头训练一次。

# 5. 常见问题

## 5.1 不要使用 `xyzrgbXYZ`

FOR-Instance 当前预处理结果没有 RGB，只有：

```txt
x, y, z, intensity, label
```

因此必须使用：

```bash
PC_ATTRIBS='xyzIXYZ'
```

如果使用 `xyzrgbXYZ`，数据加载器会报错。

## 5.2 清理旧 episode 缓存

评估 episode 会缓存为 `.h5`。FOR-Instance 的缓存目录现在会包含特征名，例如：

```bash
S_0_N_2_K_1_xyzIXYZ_episodes_100_pts_2048
S_0_N_2_K_1_xyzIXYZ_test_episodes_100_pts_2048
```

如果你修改了 `PC_ATTRIBS`、`pc_npts`、`n_way` 或 `k_shot`，建议删除对应旧缓存目录后重新生成。
