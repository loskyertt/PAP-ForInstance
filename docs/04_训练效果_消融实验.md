> [!abstract]
> 本文档分析高度分层残差原型中不同融合权重 $\lambda$ 的消融实验。固定 `B=3`（3 个高度层），对比 $\lambda = 0.01 / 0.03 / 0.05 / 0.10 / 0.20$。
> 所有实验均使用与 adapted 基线相同的预训练权重、相同的 `--pc_attribs xyzIXYZ`（7 通道），且未启用类别平衡损失。
> 其中 $\lambda=0.20$ 来自较早的 `log_forinstance_hproto` 实验目录（执行 `train_PAP_forinstance.sh` 脚本生成，已重新命名为 `log_forinstance_hproto_lambda_020`）；后续 $\lambda=0.01/0.03/0.05/0.10$ 使用 `log_forinstance_hproto_lambda_*` 目录。五组实验核心参数一致，可用于 $\lambda$ 消融对比。

# 1. 实验设置

| 参数 | 值 |
|------|:---:|
| `--use_height_proto` | True |
| `--height_proto_bins` | 3 |
| `--height_proto_weight` | 0.01 / 0.03 / 0.05 / 0.10 / 0.20 |
| `--pc_attribs` | xyzIXYZ（7 通道） |
| `--use_balanced_loss` | False |
| 预训练 checkpoint | `./logs/log_forinstance/log_pretrain_forinstance_S0`（与分支 `for-instance/innovation` 上的训练相同） |
| 其他参数 | 与 adapted 基线一致（2-way 1-shot, 40000 iters, QGPA/SR/Alignment） |

运行：

```bash
# 1. 数据预处理，若已完成可跳过
bash scripts/preprocess_forinstance.sh

# 2. 预训练，若已有 ./logs/log_forinstance/log_pretrain_forinstance_S0 可跳过
bash scripts/pretrain_forinstance.sh

# 3. 运行某个 λ 的原型训练，例如 λ=0.05
python scripts/run_hproto_config.py configs/hproto/lambda_005.yaml --phase train

# 4. 训练完成后评估同一个 λ
python scripts/run_hproto_config.py configs/hproto/lambda_005.yaml --phase eval
```

# 4. 分析与结论

## 4.1 $\lambda$ 的影响规律

| $\lambda$ 范围 | 效果 | 说明 |
|:------:|------|------|
| **0.01** | 早期达到最佳后明显回落 | 高度残差信号过弱，未能稳定改善原型匹配 |
| **0.03** | 后期才达到最佳，但整体仍偏低 | 相比 0.01 更稳定，但 eval mIoU 仍未提升 |
| **0.05** | **训练最佳**（32.81%），但泛化一般 | 训练过程 terrain 最高（72.2%），说明适度的 $\lambda$ 有助于部分 episode；但 eval 回落到 29.59% |
| **0.10** | 居中（31.18% / 30.02%） | terrain/bg/stem 较均衡但均不突出 |
| **0.20** | 训练略低于 0.05，但 **泛化最好**（32.58%） | stem 类提升最明显（16.95%），bg 也最高；但 terrain 被明显压制（50.29%） |

## 4.2 核心发现

1. **所有 $\lambda$ 值均未达到 adapted 基线（37.54%）**。这说明在当前配置下（xyzIXYZ、无平衡损失），简单加入高度分层残差原型尚未带来整体收益；它可能在部分类别上提供结构信息，但也可能干扰 QGPA 原始特征空间中 terrain/bg 的判别。

2. **$\lambda$ 存在 trade-off**：
   - $\lambda=0.01$：高度先验影响不足，训练过程明显回落。
   - $\lambda=0.03$：比 0.01 稳定，但整体收益仍有限。
   - $\lambda=0.05$：训练效果最好，但独立评估泛化不足。
   - $\lambda=0.20$：最终评估最优，但 terrain 被压制。

3. **Stem 类在 $\lambda=0.20$ 时表现最好**（16.95%），相较 $\lambda=0.01$ 提升 3.43%。但 stem IoU 并不是随 $\lambda$ 单调上升（0.03/0.05/0.10 存在波动），因此更准确的结论是：较强的高度残差信号可能更有利于树干类，但稳定收益仍需更多重复实验验证。

4. **训练过程最佳点与最终独立评估不完全一致**：$\lambda=0.03/0.05/0.10$ 的 eval mIoU 低于训练最佳 mIoU，而 $\lambda=0.01/0.20$ 的 eval mIoU 反而略高于训练最佳值。单次结果不足以统一归因为过拟合，更可能反映 few-shot episode 采样和最终 checkpoint 评估之间的波动。

## 4.3 当前评估状态

| 评估类型 | 状态 | 说明 |
|----------|:----:|------|
| ✅ **$\lambda$ 消融实验（B=3 固定）** | **已完成** | $\lambda=0.01 / 0.03 / 0.05 / 0.10 / 0.20$ 五组 |
| ❌ **B 消融实验** | **未做** | 可固定 $\lambda=0.05$ 或 $\lambda=0.20$，对比 B=2 / 3 / 4 / 6 |
| ❌ **与完整 LiDAR 属性（xyzIRNAXYZ）组合** | **未做** | 当前仅 xyzIXYZ；需先确认数据管线是否支持额外属性 |
| ❌ **与平衡损失组合** | **未做** | 当前均未启用 |

## 4.4 后续建议

1. **如果关注训练过程最优，$\lambda=0.05$ 是当前最佳训练参数**（训练 mIoU 32.81% 最高）；如果关注最终独立评估，$\lambda=0.20$ 更优（Eval mIoU 32.58%）。
2. **单独的高度分层残差原型暂未超越 adapted 基线**。后续可以在数据管线支持后验证更完整的 LiDAR 属性（如 xyzIRNAXYZ）或类别平衡损失，但这两点目前还不是本组日志能够直接证明的结论。
3. **可进一步探索自适应 $\lambda$ 调节机制**，例如让高度残差信号更多作用于 stem 区域，同时降低其对 terrain 判别的抑制。
4. **建议补充多次重复实验**。当前消融每个 $\lambda$ 只有一次训练和一次最终评估，few-shot episode 采样波动较大；后续可对关键 $\lambda=0.05/0.20$ 做多 seed 重复实验，报告均值和方差。
