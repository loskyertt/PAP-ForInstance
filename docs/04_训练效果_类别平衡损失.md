# 4. 分析与结论

## 4.1 关键发现

1. **类别平衡损失没有带来总体 mIoU 提升**  
   在 `λ=0.05`、`max_weight=5.0` 的设置下，最终 Eval mIoU 从 29.59% 小幅下降到 29.29%。训练过程最佳 mIoU 也从 32.81% 降到 29.24%。

2. **stem 有小幅收益，但不足以抵消 terrain/bg 的下降**  
   stem IoU 从 15.00% 提升到 16.70%，提升 1.70%。但 terrain 下降 6.70%，bg 下降 2.31%，因此总体 mIoU 没有改善。

3. **训练最佳点较早出现，后续没有继续刷新**  
   本次实验在 8000 iterations 达到 29.24% 的训练过程最佳 mIoU，之后 10000-40000 iterations 虽然各类 IoU 有波动，但 Best mIoU 一直没有继续提高。这可以描述为训练过程较早进入平台期，但不宜仅凭单次实验直接断言“优化不稳定”或“严重过拟合”。

4. **λ=0.20 无 BLoss 仍是当前 hproto 相关实验中最终 Eval mIoU 更高的一组**  
   λ=0.20 无类别平衡损失的 Eval mIoU 为 32.58%，高于本次 λ=0.05 + BLoss 的 29.29%。不过 λ=0.20 的 terrain 明显更低，其优势主要来自 bg 和 stem。

## 4.2 可能原因

本次类别平衡损失未带来总体提升，可能有以下原因：

- **episode 内类别点数波动较大**：当前实现按单个 query episode 中各类点数动态计算权重。few-shot episode 的点数分布本身波动较大，动态权重可能引入额外噪声。
- **background / terrain 被相对削弱**：类别平衡会提高少数类权重，同时相对降低多数类影响。本次结果中 terrain 和 bg 均下降，说明加权目标可能牺牲了原本较稳定的类别。
- **`max_weight=5.0` 可能偏激进**：虽然权重做了上限和归一化，但对于 1-shot 点云分割任务，5.0 的上限仍可能过强。
- **与高度残差原型存在叠加效应**：高度残差原型已经改变了前景类别的相似度分布，再叠加动态类别权重后，可能进一步放大 stem，但也更容易损失 terrain/bg。

# 6. 后续建议

1. **不要把当前 `max_weight=5.0` 作为最终推荐设置**。本次实验显示它只带来 stem 小幅提升，却损失 terrain/bg。
2. **优先尝试更温和的类别平衡权重**，例如 `max_weight=2.0` 或 `3.0`，并继续固定 `λ=0.05`。
3. **补做“无高度原型 + BLoss”的对照实验**，确认 BLoss 本身是否有效，而不是只观察它与高度原型叠加后的结果。
4. **若实验成本有限，当前阶段不建议继续扩大 BLoss 网格**。相比继续调 BLoss，完整 LiDAR 属性或自适应高度残差权重可能更值得优先探索。

结论：**在当前 `xyzIXYZ + λ=0.05 + max_weight=5.0` 配置下，类别平衡损失没有提升总体表现；它略微改善 stem，但明显牺牲 terrain 和 bg。**
