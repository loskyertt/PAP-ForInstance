## 1.1 数据采集机构/集合标识

`CULS`、`NIBIO`、`RMIT`、`SCION`、`TUWIEN` 代表 **5 个独立的数据采集合作机构**，每个集合对应特定的国家、森林类型、传感器配置与采集协议。具体信息如下：

| 文件夹名       | 全称与机构                                                           | 国家   | 森林类型              | 采样设计               | 点密度 (pts/m²) | 叶相条件         |
| ---------- | --------------------------------------------------------------- | ---- | ----------------- | ------------------ | ------------ | ------------ |
| **NIBIO**  | Norwegian Institute for Bioeconomy Research                     | 挪威   | 北方针叶林（挪威云杉为主）     | 样地级（20 个固定样地）      | 9,529        | Leaf-on      |
| **CULS**   | Czech University of Life Sciences, Prague                       | 捷克   | 温带针叶林（苏格兰松人工林）    | 样地级（3 个样地）         | 2,585        | Leaf-on      |
| **TUWIEN** | TU Wien, Department of Geodesy and Geoinformation               | 奥地利  | 冲积落叶林（天然混交林，结构复杂） | 连续覆盖（wall-to-wall） | 1,717        | **Leaf-off** |
| **RMIT**   | Royal Melbourne Institute of Technology, University of Tasmania | 澳大利亚 | 干旱硬叶桉树林（白薄荷桉）     | 连续覆盖（wall-to-wall） | 498          | Leaf-on      |
| **SCION**  | Scion (New Zealand Forest Research Institute)                   | 新西兰  | 温带人工针叶林（辐射松纯林）    | 样地级（5 个样地）         | 4,576        | Leaf-on      |

> [!tip] **关键提示**
> 1. **森林异质性**：5 个集合覆盖了从北方针叶林到热带桉树林、从天然林到人工林的典型梯度，是评估模型泛化能力的核心设计；
> 2. **唯一落叶期数据**：`TUWIEN` 为 leaf-off 条件，枝干结构更清晰但冠层信息缺失，适合研究季节适应性；
> 3. **点密度差异显著**：`NIBIO`（9,529 pts/m²）与 `RMIT`（498 pts/m²）相差近 20 倍，需在预处理中考虑归一化或重采样。

## 1.2 `.las` 文件命名规则解析

### 1.2.1 样地级集合（NIBIO / CULS / SCION）

**命名格式**：`plot_XX_annotated.las`

| 字段 | 含义 | 示例 |
|-----|------|------|
| `plot_` | 标识为固定面积样地（plot-level sampling） | — |
| `XX` | 样地唯一编号（非连续，因原始调查设计而异） | `plot_1`, `plot_10`, `plot_31` |
| `_annotated` | 表示该文件已包含人工标注的 `treeID`（实例）与 `Classification`（语义）字段 | — |

✅ **使用建议**：
- 同一集合内不同 `plot_XX` 文件相互独立，可并行加载；
- 需结合 `data_split_metadata.csv` 中的 `split` 字段判断该样地属于 `dev` 或 `test` 子集。

### 1.2.2 连续覆盖集合（RMIT / TUWIEN）

**命名格式**：`train.las` / `test.las`

| 文件名 | 含义 | 说明 |
|-------|------|------|
| `train.las` | 开发集（约 70% 区域） | 可用于训练 + 验证（需自行划分） |
| `test.las` | 测试集（约 30% 区域） | **严禁用于训练**，仅用于最终评估 |

✅ **使用建议**：
- 此类文件为单一大文件，建议使用空间索引（如 PDAL 的 `--filters.hexbin`）或分块读取以提升效率；
- 边界处可能存在跨 `train`/`test` 的树木，评估时需严格按 `treeID` 匹配，避免空间泄漏。

# 2. 点云数据字段（.las 文件内嵌）

当读取 `.las` 文件时，可以查看到有以下字段：

```txt
=== 点云字段 ===
['X', 'Y', 'Z', 'intensity', 'return_number', 'number_of_returns', 'scan_direction_flag', 'edge_of_flight_line', 'classification', 'synthetic', 'key_point', 'withheld', 'scan_angle_rank', 'user_data', 'point_source_id', 'gps_time', 'red', 'green', 'blue', 'treeID', 'treeSP']
```

> [!warning] 关于 `treeSP` 字段的特别说明
> `treeSP`（树种标识）**并未在 FOR-instance 官方发布规范中定义**。  
> 论文原文第 *Forest types* 章节明确指出：
>> *"While the tree species information was unavailable for all collections and thus not published in FOR-instance data, most trees were coniferous(60%) and primarily found in productive forests."*
>
> **学术建议**：
> 1. `treeSP` 极可能是原始数据提供方（如 CULS 或 NIBIO）内部保留的字段，或在用户下载/解压过程中由第三方工具自动附加。
> 2. **严禁将其作为基准测试的监督标签或评估依据**。FOR-instance 的官方 Benchmarking 协议仅以 `classification` 与 `treeID` 为准，引入未经验证的树种标签将导致实验结果不可复现且偏离论文设定。

该数据集的字段可严格划分为三类：**核心人工标注字段**、**激光雷达传感器原始字段**以及 **LAS 标准元数据与控制标志位**。

以下为逐项专业释义及论文依据对照：

## 2.1 核心人工标注字段（模型训练监督标签）

| 字段名                  | 数据类型           | 含义说明                      | 论文依据与使用规范                                                                                                                                                          |
| :------------------- | :------------- | :------------------------ | :----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`classification`** | `uint8`        | **语义分割标签**：存储点云的细粒度结构类别编码 | 论文表3明确定义：`0`=未分类, `1`=低矮植被, `2`=地形, `3`=边界外点, `4`=树干, `5`=活枝, `6`=枯枝。训练时需按需聚合（如 `5+6→树冠`）。                                                                         |
| **`treeID`**         | `uint32`（扩展字节） | **实例分割标签**：单木唯一标识符        | 原文指出：“The tree unique identifier was stored as an additional treeID column in the .las files.” `treeID>0` 代表独立树木实例；`treeID=0` 代表非树木点（地面、林下植被、边界外点等），推理时需保留，评估时需掩膜。 |

**语义分类编码表（存储于 `Classification` 字段）**：

| Code  | Class Name     | 中文释义   | 标注区域点数占比 | 备注                             |
| ----- | -------------- | ------ | -------- | ------------------------------ |
| **0** | Unclassified   | 未分类点   | 0.01%    | 可安全掩膜，不影响评估                    |
| 1     | Low-vegetation | 低矮植被   | 17.42%   | 含林下小树、灌木、草本；与 Terrain 存在部分重叠   |
| 2     | Terrain        | 地形/地面  | 8.96%    | 经 CSF 滤波提取，不含绿色植被              |
| **3** | Out-points     | 边界外点   | 42%*     | 样地边界外的未标注点；推理时需保留，评估时忽略        |
| 4     | Stem           | 树干     | 5.1%     | 主干轴线；高处因遮挡标注质量略低               |
| 5     | Live branches  | 活枝     | 63.8%    | 带叶/针的枝条；为主冠层组成部分               |
| 6     | Woody branches | 枯枝/木质枝 | 4.66%    | 无叶木质枝条；与 Live branches 边界存在主观性 |

> *注：Out-points 占比为总点数（含未标注区域），其余比例为标注区域内点数占比*。

## 2.2 激光雷达传感器原始字段（模型输入特征）

| 字段名                     | 含义说明                  | 论文依据                                              |
| :---------------------- | :-------------------- | :------------------------------------------------ |
| **`X, Y, Z`**           | 三维空间坐标（单位：米，投影坐标系）    | 原始点云几何基准。论文建议使用局部归一化或相对坐标以消除绝对位置偏差。               |
| **`intensity`**         | 激光回波强度，反映地物表面反射率      | 原文提及可作为基础输入特征。常用于区分木质部与叶片、辅助地面滤波。                 |
| **`return_number`**     | 当前脉冲的回波序号（1为首回波，依次递增） | 体现冠层穿透深度。首回波多对应冠层顶部，末回波多对应地表或粗枝干。                 |
| **`number_of_returns`** | 单次脉冲激发的总回波数           | 与 `return_number` 结合可计算回波穿透率，辅助判断点云遮挡程度。          |
| **`scan_angle_rank`**   | 扫描偏角（相对于天底方向）         | 原文提及为 `scan angle`。偏角过大会导致点云拉伸与密度衰减，部分框架会据此加权或过滤。 |

## 2.3 LAS 标准元数据与控制标志位（通常不参与网络前向传播）

| 字段名 | 含义说明 | 处理建议 |
|:---|:---|:---|
| `scan_direction_flag` | 扫描方向标志（0=左至右，1=右至左） | 飞行轨迹元数据，一般不用于特征提取。 |
| `edge_of_flight_line` | 航带边界点标志 | 边缘点常存在几何畸变或密度异常，预处理时可考虑掩膜或降权。 |
| `synthetic` | 人工合成点标志（通常应为0） | 若为1表示由算法插值生成，非真实传感器采集，建议过滤。 |
| `key_point` | 关键特征点标志（用于构建TIN） | 摄影测量衍生字段，纯LiDAR任务中通常为0。 |
| `withheld` | 剔除标志（1表示该点应从后续处理中排除） | 若为1，表明原始数据已标记为异常/噪声，**必须掩膜**。 |
| `user_data` | 用户自定义字节（通常预留为0） | 本数据集中未用于存储标注，可忽略。 |
| `point_source_id` | 数据源标识（通常为航带编号或文件ID） | 用于区分不同飞行架次，不参与模型学习。 |
| `gps_time` | 激光脉冲发射的精确时间戳（双精度浮点） | 用于时序对齐或运动补偿，语义分割任务中通常丢弃。 |
| `red, green, blue` | RGB颜色通道（LAS 1.4标准为 `uint16`，范围0–65535） | **注**：纯机载LiDAR通常不含RGB。该字段存在说明原始数据可能已与正射影像（DOM）进行过辐射配准。若使用，需除以65535归一化；若部分点缺失，建议降级使用 `intensity` 扩展为三通道。 |

> [!warning]
> **论文中未对 `red`、`green`、`blue` 这三个字段进行任何说明、定义或使用建议**。

在 **"Instance segmentation"** 章节（Data usage → Method development 部分），论文明确指出可用于模型输入的传感器原始数据为：

> *"In addition to the available sensor data, i.e. **x, y, z, intensity, return number, number of returns, and scan angle**, users can further append new features such as geometrical features derived from normal vectors."*

即官方认可的基础输入特征仅包含以下 7 项：
| 字段 | 含义 |
|-----|------|
| `x, y, z` | 三维空间坐标 |
| `intensity` | 激光回波强度 |
| `return_number` | 当前回波序号 |
| `number_of_returns` | 单次脉冲总回波数 |
| `scan_angle` | 扫描偏角 |

> **结论**：`red` / `green` / `blue` 未出现在上述列表中，也未在摘要、方法、数据描述、表格或图注中被提及。这三个字段是 LAS 文件格式的**可选扩展字段**，但**不属于 FOR-instance 基准测试的官方定义或推荐输入**。其存在不影响标注字段（`classification` / `treeID`）的使用，但在方法对比实验中需谨慎处理以确保公平性。

# 5. 注意事项

1. **标注局限性提醒**（论文明确指出）：
   - `Live branches` 与 `Woody branches` 的区分在针叶林中主观性强，**不等同于精确的叶–木分离**；
   - `Terrain` 与 `Low-vegetation` 因滤波策略存在边界模糊，建议按需合并或重分类；
   - 高处树干因遮挡标注不完整，评估时需考虑区域加权策略。

2. **任务适配建议**：
   - **语义分割**：直接以 `Classification` 为标签，支持类别聚合（如 `Stem+Branches→Tree`）；
   - **实例分割**：以 `treeID` 为实例标识，需注意 `treeID=0` 的背景点处理策略；
   - **全景分割**：联合使用 `treeID` + `Classification`，实现“哪棵树 + 是什么部件”的联合预测；
   - **参数反演**：关联 `DBH_cm` 与分割结果，构建回归/检测多任务框架。
