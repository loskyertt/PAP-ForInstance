## 5. 学习建议

### 如何阅读代码

1. **先看整体结构**：用 `tree` 或 IDE 浏览目录，建立文件层级的心智模型
2. **跟数据流走**：从 `dataloader` → `model` → `loss` → `training loop` 的顺序阅读
3. **打印中间张量形状**：在关键节点插入 `print(x.shape)` 理解数据维度变化
4. **画调用图**：追踪每个 forward 函数被谁调用

### 如何做实验

1. **先跑通预训练**：`pretrain_segmentor.sh` 是最基本的实验
2. **小规模验证**：先用 `n_way=2, k_shot=1, n_queries=1` 快速验证
3. **对比消融实验**：逐个关闭 `--use_attention`、`--use_transformer` 等选项
4. **记录日志**：使用 TensorBoard 可视化训练曲线

### 如何验证理解

> 如果你能回答以下问题，说明你已经掌握对应阶段：

| 阶段 | 验证问题 |
|---|---|
| 阶段1 | main.py 有哪些 phase？各自做什么？ |
| 阶段2 | Episode 是如何构建的？为什么要用 HDF5 缓存？ |
| 阶段3 | EdgeConv 和普通 Conv1d 的本质区别是什么？ |
| 阶段4 | 原型是如何从 support 特征计算出来的？ |
| 阶段5 | QGPA 的 Q, K, V 分别对应什么？ |
| 阶段6 | GMMN 生成的伪原型如何与真实原型对齐？ |
| 阶段7 | IoU 是如何计算？mean IoU 和 per-class IoU 有什么区别？ |
| 阶段8 | MPTI 和 ProtoNet 的根本区别是什么？ |

### 常见误区

| 误区 | 正确理解 |
|---|---|
| 认为点云和图像差不多 | 点云是无序的、稀疏的、非结构化的，需要特殊的卷积操作 |
| 混淆原型和分类器权重 | 原型是 support 样本的嵌入均值，不是可学习参数 |
| 认为 Episode 越多越好 | Episode 多样性和难度平衡更重要 |
| 忽略预处理的重要性 | 点采样、归一化、数据增强直接影响最终性能 |
